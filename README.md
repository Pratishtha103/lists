# HTML Lists — The Odin Project

A simple HTML webpage created as part of **The Odin Project** Foundations curriculum to practice using ordered and unordered lists.

## Overview

This project demonstrates the basic structure of HTML lists, including:
- **Unordered Lists (`<ul>`)**: Used for items where order doesn't matter (favorite foods and dream travel destinations).
- **Ordered Lists (`<ol>`)**: Used for ranked or sequential items (daily to-dos and top 5 favorite movies).
- **List Items (`<li>`)**: Used to define each individual entry inside a list.

## How to View

1. Clone or download this repository.
2. Open the `index.html` file in any web browser.
